# Weather

Current conditions for one named place, using Open-Meteo's public geocoding and forecast APIs. Set **Location** to a city, region or postal code; it needs no account, token or Home Assistant installation.

The bar stays absent in ordinary weather. Rain, fog, wind, severe conditions, or a temperature outside the configured comfort band bring it back with a condition glyph and temperature. Its popover keeps only the useful current details: feels-like temperature, humidity, wind and precipitation.
