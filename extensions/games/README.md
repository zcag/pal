# Games

Every game pal has in one list. Enter on the Games row opens it: one
row per game with its tile and tagline, sorted by name, and Enter on a
row opens that game (Escape comes back to the list).

The list is not kept here: every open reads the installed extensions'
manifests and takes each view palette of an extension the store shelves
under Fun. Today that is 2048, Blackjack, Minesweeper, Snake II,
Solitaire, Wordle and Yahtzee; a game installed from the store's Fun
shelf shows up the next time the list opens.

## Keyboard

| keys | action |
| --- | --- |
| `enter` | Play the game |
| `escape` | Back to the root |

## Setup

Nothing to install and no settings.

## Platforms

macOS and Linux, the same on both.
